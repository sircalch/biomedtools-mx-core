# Checklist de prueba con 2 a 5 personas

## Objetivo

Detectar problemas de claridad, navegacion, celular, contenido y reporte antes de aplicar el piloto formal con estudiantes.

## Perfil sugerido

- 2 alumnos de confianza.
- 1 companero docente.
- 1 persona con perfil biomedico o tecnico.
- 1 prueba propia en modo incognito y celular.

## Flujo a probar

1. Entrar a https://biomedtools-mx-core.vercel.app
2. Abrir BioMed Quiz Arena.
3. Seleccionar Monitoreo de signos vitales.
4. Resolver el quiz.
5. Guardar captura del resultado.
6. Abrir el caso relacionado.
7. Resolver Monitor sin lectura de SpO2.
8. Abrir Report Builder desde el boton del resultado.
9. Confirmar que el reporte este prellenado.
10. Descargar o guardar el PDF.
11. Contestar encuesta post-uso.

## Preguntas de revision rapida

1. Se entendio que hacer desde el inicio?
2. Algun boton confundio?
3. Algo fallo en celular?
4. Las preguntas fueron claras?
5. El caso se sintio realista?
6. El reporte se vio formal?
7. El flujo tomo demasiado tiempo?
8. Algo se vio poco profesional?

## Criterio para avanzar al piloto formal

Avanzar solo si no hay errores bloqueantes en:

- Acceso al Core.
- Quiz de monitoreo.
- Redireccion a Case Simulator.
- Caso monitor sin lectura de SpO2.
- Boton hacia Report Builder.
- Prellenado y descarga de reporte.
