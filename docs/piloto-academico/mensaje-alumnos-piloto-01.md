# Mensaje para alumnos

Actividad piloto: BioMedTools MX Core - Monitoreo SpO2

## Instrucciones

1. Ingresa a:
   https://biomedtools-mx-core.vercel.app

2. Abre BioMed Quiz Arena.

3. Selecciona la categoria:
   Monitoreo de signos vitales.

4. Resuelve el quiz y guarda captura del resultado.

5. Abre BioMed Case Simulator.

6. Resuelve el caso:
   Monitor sin lectura de SpO2.

7. Al terminar, abre Report Builder desde el boton de reporte.

8. Revisa que el reporte este prellenado.

9. Completa datos faltantes segun indique el docente.

10. Descarga o guarda el reporte.

11. Contesta la encuesta final.

## Entregables

- Captura del resultado del quiz.
- Captura del resultado del caso.
- Reporte tecnico PDF.
- Encuesta final contestada.

## Aviso educativo

Esta actividad es una simulacion academica. No sustituye protocolos clinicos, supervision profesional, normativas institucionales ni mantenimiento biomedico certificado.
