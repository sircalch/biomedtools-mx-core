## Orden recomendado

1. Rotar la key `service_role` de Supabase si fue compartida fuera del dashboard.
2. Revisar manualmente preguntas, casos y reportes.
3. Ejecutar un piloto pequeno con 5 a 15 estudiantes.
4. Guardar capturas, reportes PDF, encuesta y observaciones.
5. Corregir contenido con base en resultados reales.
